# Site LithoShape3D

Site statique (HTML + CSS + un peu de JavaScript, aucune dépendance, aucun build).

- `index.html` : version française. `en/index.html` : version anglaise.
- `assets/img` : visuels du produit (rendus et captures du logiciel). `assets/fonts` : Inter (licence SIL OFL).
- Aperçu local : `python3 -m http.server 8765` puis http://localhost:8765/

## Mettre en ligne gratuitement
- **GitHub Pages** (déjà utilisé pour le guide) ou **Cloudflare Pages** : on publie ce dossier tel quel.
- Adresse gratuite : `https://<nom>.pages.dev` (Cloudflare) ou `https://<compte>.github.io/<dépôt>/`.
- Un nom de domaine à soi (environ 10 €/an) est facultatif : il se branche ensuite sans changer le site.
